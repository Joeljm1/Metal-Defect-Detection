## 🚀 Step-by-Step Learning Curriculum

Run these scripts sequentially in your terminal:

### Step 0: Write the Entire Dataset & DataLoader from Pure Scratch (ZERO Imports)
```bash
python learn/00_dataset_from_scratch.py
```
**What this teaches you:**
* **NO `src` imports.** Only standard Python, OpenCV, and PyTorch.
* How to open and parse raw YOLO label `.txt` files line by line using basic Python file I/O.
* The exact bounding box math: converting normalized `(xc, yc, w, h)` into pixel corners `[xmin, ymin, xmax, ymax]`.
* How to write a PyTorch `Dataset` subclass (`__init__`, `__len__`, `__getitem__`) with OpenCV image loading, color conversion (BGR $\to$ RGB), and normalization to $[0, 1]$.
* **Why PyTorch's default `DataLoader` crashes on Object Detection**, and how to write a custom `collate_fn` that handles images with different numbers of bounding boxes.

### Step 1: Explore the Dataset & PyTorch DataLoader
```bash
python learn/01_explore_dataset.py
```
**What this teaches you:**
* How images and bounding boxes are stored in YOLO format: `<class_id> <x_center> <y_center> <width> <height>`.
* Why coordinates are normalized between $0.0$ and $1.0$.
* How the PyTorch `NEUDataset` and `DataLoader` batch images into 4D tensors `(B, 3, 200, 200)`.
* Generates a visual ground-truth verification image saved to `learn/output/sample_ground_truth.png`.

---

### Step 2: Inspect the Baseline Model (CSPDarknet + PANet + Head)
```bash
python learn/02_inspect_baseline_model.py
```
**What this teaches you:**
* The 3 core stages of the baseline detector:
  1. **Backbone (CSPDarknet):** Extracts hierarchical features at Stride 8 ($P_3: 25\times 25$), Stride 16 ($P_4: 13\times 13$), and Stride 32 ($P_5: 7\times 7$).
  2. **Neck (PANet):** Fuses high-level semantic context with fine-grained spatial resolution.
  3. **Head (DetectHead):** Predicts 3 anchor boxes per grid cell across all 3 scales.
* The exact math behind candidate bounding boxes:
  $$(25 \times 25 \times 3) + (13 \times 13 \times 3) + (7 \times 7 \times 3) = 1,875 + 507 + 147 = \mathbf{2,529\text{ candidate boxes!}}$$
* Why the baseline has **7.20 million parameters**, keeping it fast enough for edge devices.

---

### Step 3: Run Defect Detection Inference on a Real Test Image
```bash
python learn/03_run_inference.py
```
**What this teaches you:**
* How to load trained PyTorch checkpoint weights (`checkpoints/M1_Baseline_best.pt`).
* How a test image is resized to $200\times 200$, normalized to $[0, 1]$, and passed through `model(image)`.
* **Non-Maximum Suppression (NMS):** Out of 2,529 raw candidate boxes, 99% are background noise. NMS applies:
  * A confidence threshold ($0.25$) to discard low-probability candidates.
  * An IoU threshold ($0.45$) to suppress duplicate overlapping boxes.
* Saves the resulting defect detection image with labeled boxes to `learn/output/baseline_prediction.png`.

---

### Step 4: How Neural Networks Learn (One Training Step)
```bash
python learn/04_train_one_step.py
```
**What this teaches you:**
* The multi-task loss function:
  $$\mathcal{L}_{\text{total}} = \lambda_{\text{box}} \mathcal{L}_{\text{CIoU}} + \lambda_{\text{obj}} \mathcal{L}_{\text{obj\_BCE}} + \lambda_{\text{cls}} \mathcal{L}_{\text{cls\_BCE}}$$
* **Backpropagation:** How PyTorch calculates gradients $\nabla_W \mathcal{L}$ using the chain rule (`total_loss.backward()`).
* **Optimizer step:** How the AdamW optimizer updates all 7.2 million weights (`optimizer.step()`).
* Verifies that the loss immediately decreases on the same batch after the update!

## 💡 Quick Reference: Common Viva Questions

| Question | Answer |
| :--- | :--- |
| **What is the baseline detector?** | **YOLOv5s** with a CSPDarknet backbone, a PANet feature fusion neck, and a 3-scale anchor head. |
| **How many parameters does it have?** | **7.20 Million parameters** (configured with depth multiple $0.33$ and width multiple $0.50$). |
| **Why does it predict 2,529 boxes?** | Because it uses 3 anchor templates across three grid resolutions ($25\times 25$, $13\times 13$, and $7\times 7$). |
| **What loss function is used for bounding boxes?** | **Complete-IoU (CIoU) loss**, which penalizes overlap, center-point distance, and aspect ratio discrepancy simultaneously. |
